1. **失败归因的判定基准是空白**：现有最强方法步级 14.2%（Who&When）、通用轨迹模型定位 11%（TRAIL），且判定器全为 LLM、金标准全为人工标注。

3. **相关工作需说明与 `coder/balatrobench` 的差异**（非命名规则）：GitHub 上已有 `coder/balatrobench`（LLM 排行榜/结果分析），与本项目目标不同——本项目是长线规划测试集，失败归因仅作诊断报告层。
