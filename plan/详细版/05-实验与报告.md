## 1. 实验矩阵（v3.0：训练集 90 局 + 真游戏 12 局）

### 1.1 训练集主实验（ATE，3 组 × 30 场景 = 90 局）

| 组 | 模型 | Prompt | 工具 | 想回答 |
|---|---|---|---|---|
| **A** | 本地 4B（q4） | 直接给动作 | 4 个 | 下界基线 |
| **B** | 本地 4B（q4） | CoT（先写推理再给动作） | 4 个 | CoT 对小模型有用吗 |
| **C** | 云端模型 | CoT | 4 个 | 规模差异有多大 |

- 规模：**3 组 × 30 场景 = 90 episode**（每场景 1 次）。60 个决策点是场景池；主表实际纳入的 30 个场景与选取规则在预注册中冻结（📋）。
- 串行跑，预计 **4–6h**（含排错）；比 v2.1 的 180 局少一半，为真游戏终验腾时间。
- **可选 D 组**（仅当时间富余）：云端 + 显式“先调 `get_state` 再决策”强约束，测 Tool Use 纪律性。一旦加 D 组，必须相应缩减其他章节，否则 W5 做不完。

### 1.2 真实游戏终验（RGFT，3 组 × 4 局 = 12 局）📋

| 项 | 值 | 说明 |
|---|---:|---|
| 配置组 | 3 组（A/B/C，与主实验一致） | 便于“训练集 vs 真游戏”对照 |
| 每组局数 | 4 局 | 单局 5–15 分钟；总 12 局是本机时间上限 |
| 单局范围 | Ante 1 三盲注（Small 300 / Big 450 / Boss 600） | Red Deck + White Stake；Boss 效果只记录不模拟 |
| 单局上限 | 15 分钟或 3 盲注结束 | 超时记 `timeout`，不剔除，单列 |
| 统计口径 | **描述统计 + bootstrap 95% CI** | n=12，**不做显著性主张** |
| 环境 | Balatro 1.0.1o + Lovely + Steamodded + balatrobot（📋 尚未接入） | 版本链写入 `scenarios/v3/MANIFEST.json` |

> 终验是**最终环境测试**，不是批量主环境；不可达时按 07 §6.5 降级为 `CAPTURE_REPLAY_ONLY` 并如实声明，**不得**用训练集结果替代。

**总计**：训练集 90 局 + 真游戏 12 局 = **102 局**；另需预留 4–6h 真游戏时间与 3–5h 环境安装（W3）。

## 2. 基线

| 基线 | 说明 | 用途 | 环境 |
|---|---|---|---|
| **Random** | 均匀随机选合法动作 | 下界，验证指标不是噪声 | 训练集 |
| **Greedy-Oracle** | 每步取 Local Oracle 最优 | 上界参照（≈0 regret，用于验证流水线） | 训练集 |
| 被测组 A/B/C | 见上 | 实验主体 | 训练集 + 真游戏终验 |

> Greedy-Oracle 跑通 = 整条链路正确（若它的 regret 不接近 0，说明 oracle 或评分有 bug）。
> **真游戏终验不设 Random 基线**：n=12 且单局成本高，只做 A/B/C 三组描述统计；不声称“优于随机”。

## 3. 指标与统计

### 3.1 训练集主表（90 局）

| 指标 | 组间比较方法 | 报告内容 |
|---|---|---|
| Local Regret | 配对 Wilcoxon | 中位数、p、rank-biserial、bootstrap 95% CI；`exact=false` 场景单列 |
| Action Optimality | McNemar | 差值、p、CI |
| Legality Rate | McNemar（合法/非法） | 同上 |
| Episode Progress | 描述统计（样本少） | 分布 + 均值 CI，不做检验 |
| 失败类型分布 | 卡方/Fisher（若样本够） | 占比 + CI；**E1 单列** |
| Cost / Latency | 描述统计 | 每局 token、每局秒、每决策秒 |

> **五层口径（v4.0）**：本表只覆盖 ① 合规门禁、② 单步战术、⑤ 诊断解释三层；③ 跨期资源分配层与 ④ 长程进度/失败恢复层**当前均未覆盖**（W3 候选，定义见 [03](03-评测集与指标.md) §3）。Local Regret 只衡量单步，**不得单独用来支撑“长线规划”主张**。

**多重比较**：3 组两两 = 3 次比较 → **Holm 校正**，报告校正后 p。
**必须同时给出**：n、效应量、CI。只给 p 的结论不接受。

### 3.2 真游戏终验（12 局，描述统计）📋

| 指标 | 定义 | 报告内容 |
|---|---|---|
| `blinds_cleared` | 通过的盲注数 / 3 | 分布 + 中位数 + bootstrap 95% CI |
| `ante1_win` | 是否打完 Ante 1 | 每组的通过局数（x/4），不报 p |
| `legality_rate` | 合法工具调用 / 总调用 | 每组的比率 |
| `timeout_rate` | 超时局数 / 12 | 单列，不剔除 |
| `agent_failure_class` | F1–F4 + F0 | 计数与占比（描述） |
| `env_divergence` | E1 条数 / 决策数 | **单列**，不进 Agent 失败率 |
| `real_vs_training_gap` | 训练集 regret 与终验表现的方向性差异 | 只描述方向（同向/反向/无法判断） |
| `cost` | token/局、秒/局、$/局 | 必报 |

> **统计纪律**：n=12，只做描述统计与 bootstrap CI，**不报 p 值、不做“显著优于”结论**；报告限制章必须单列这一点（D10/D17）。

## 4. 预注册（跑实验前冻结，打 git tag）

```markdown
# prereg v3
- 主指标：Local Regret（L1+L2，按场景数加权；exact=false 场景单列或分层）；**它只衡量单步，不作为长线规划证据**——③ 跨期资源分配与 ④ 失败恢复本轮未覆盖，不写进结论
- 次指标：Action Optimality、Legality Rate、首次失败步、Cost
- 主对比：A vs C（规模差异）；次对比：A vs B（CoT）
- 检验：配对 Wilcoxon + McNemar，α=0.05，Holm 校正（3 次）
- 训练集样本量：每组 30 场景（3 组 = 90 局）；主表 30 场景的选取规则在此冻结
- 真游戏终验：3 组 × 4 局 = 12 局，只做描述统计 + bootstrap 95% CI，不做显著性主张
- 首次失败步阈值：regret ≥ 0.5（冻结，不自适应）
- 归因一致性：计划 n=30（降级档 n=24）；总体 κ + per-class κ（每类 n≥5 才单独报）+ 混淆矩阵 + 弃权率；F4 不进任何显著性检验
- 环境分歧：E1 单列，不进 Agent 失败率；判定顺序 F1–F4 优先于 E1
- 剔除：基础设施错误（超时/MCP 断连/模型 5xx）可重跑一次并记录；模型决策错误不剔除；真游戏超时单列不剔除
- 禁止：跑后更换主指标、新增事后子组、只报显著结果、把训练集结果当终验、把 Pass^k 补做当结论
```

> **预注册与 `07` 同步**：终验协议（12 局、Ante 1、15 分钟上限、描述统计）以 07 §6.1 为准；本文件只落地执行细节。
